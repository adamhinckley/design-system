## Features

- **Range Selection**: Pick both start and end dates in one control
- **3 Sizes**: `sm`, `md`, `lg`
- **22 Colors**: Full Tailwind palette with light/dark support
- **Month/Year Picker**: Optional dropdown navigation for faster date jumps
- **Optional Transparent Trigger**: `removeBackground` for layered layouts
- **Locale Support**: Locale-aware formatting for displayed date ranges
- **Controlled + Uncontrolled**: Controlled props or default values for simple forms
- **Accessibility**: Labeling, required/invalid states, keyboard-safe focus and dialog semantics

## Usage Guidance

- Use **DateRangePicker** when users need to select both start and end dates together.
- Use `enableMonthYearPicker` for faster navigation across distant months or years.
- Use `startSelected`/`endSelected` + callbacks for controlled form state.
- Use `defaultStartSelected`/`defaultEndSelected` for simple uncontrolled setup.
- Use `locale` to localize displayed range text and calendar labels.
- Use `errorText` for validation feedback and `helperText` for supportive guidance.
