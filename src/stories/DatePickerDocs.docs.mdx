## Features

- **3 Sizes**: `sm`, `md`, `lg`
- **22 Colors**: Full Tailwind palette with light/dark support
- **Month/Year Picker**: Optional dropdown-based month/year selection
- **Optional Transparent Trigger**: `removeBackground` for blended layouts
- **Internationalization**: Locale-aware date formatting and calendar labels
- **Controlled + Uncontrolled**: `selected` and `defaultSelected` support
- **Accessibility**: Labeling, invalid/required states, keyboard-safe focus

## Import

```tsx
import { DatePicker } from "@adamhinckley/design-system";
```

## Usage Guidance

- Use **DatePicker** for single-date selection with consistent design-system styling.
- Use `enableMonthYearPicker` when users need faster navigation across distant dates.
- Use `selected` + `onDateChange` for controlled forms, or `defaultSelected` for simpler uncontrolled usage.
- Use `locale` to localize formatted values, month names, and weekday labels.
- Use `errorText` to communicate validation failures and `helperText` for supportive guidance.
